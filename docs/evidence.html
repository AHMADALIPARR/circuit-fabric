This console executes the Phase I exchange on BEAM: the real circuit actor decides legal transitions, pricing.erl computes every charge, and the frame codec runs here. A passing row below is a property of this running model. It is not a Why3 discharge, a p4c run, or a synthesis report.

What was actually run

  • Phase I definitions

    Executing on BEAM in this console. State machine, resource conservation, tariff formula, frame layout.

  • control/beam/circuit_actor.erl

    Executing. One gen_statem process per circuit decides transition legality. Resource reservation is performed here, in the orchestration layer, as the actor's contract states.

  • accounting/pricing.erl

    Executing. Its exported components compute every charge in this console; nothing is transcribed. basic_charge_test constants are T1. Expected settlement is 2500 minor units.

  • TLA+ CircuitState.tla

    TLC ran against the committed model and configuration in the source repository: 6,271 generated states, 1,650 distinct. TypeOK, NoOverCommit, ReservedOnlyWhenHeld, and FreeHasZero hold.

  • WhyML / Why3 and Dafny

    Not discharged. Phase II work, in that order: Why3 arithmetic and capacity proofs, then Dafny contracts.

  • P4_16 circuit_forward.p4

    Source only. p4c was not run. The header layout was verified field-for-field against the corrected spec: 160 bits, network order, magic 0x5343.

  • VHDL scf_crossbar

    Source only. No GHDL log. No resource or timing numbers.

  • Gödel

    Blocked. No compiler. Admission here executes the relations in control/godel/README.md as Erlang. It is not a Gödel execution.

  • UUIE-Array accounting extension

    The C11 engine in the source repository passes its 117-check acceptance suite under ASan/UBSan. It is not wired into this console.

Invariants of this model

  • PASSidentityNo circuit id 0. Non-FREE identities unique.
  • PASSfree-zeroFREE circuits hold no bandwidth and no table entries.
  • PASSreservation-heldFrom RESERVED until release, bandwidth stays positive. Includes FAILED after a successful reserve.
  • PASStablesForwarding entries exist only after a completed install, and are cleared on release or rolled-back install.
  • PASSfinal-onceRELEASED iff exactly one final accounting event for this lifecycle.
  • PASSconservationEach link's reserved_bps equals the sum of circuits still holding that link.
  • PASSno-overcommitreserved_bps ≤ capacity_bps on every link.
  • PASSledger-idempotentAccounting events unique by (circuit, lifecycle, seq). Amounts are integers.
  • PASStariff-lockTariff version locks at ADMITTED and clears on recycle.

spec/README.md named circuit_id.md and invariants.md. Both were authored from the existing definitions during the baseline alignment and are in the source repository.

Magic was written as 0xSCF1. S is not a hexadecimal digit. The baseline set the value to 0x5343, the ASCII encoding of “SC”, in the spec and the P4 parser. Frames here use 0x5343.

The TLA+ model's Fail action is generic and the model has no Timeout action; the spec table restricts fail and defines timeout. The actor and this console follow the spec. Model alignment is Phase II TLA+ work.
